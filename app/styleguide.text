1. สี (DESIGN TOKENS)
----------------------------------------------------------
สีหลัก (น้ำเงิน)
  primary-700   #1E40AF   hover / pressed
  primary-600   #1D4ED8   ปุ่มหลัก ลิงก์ เมนูที่เลือก
  primary-500   #3B82F6   focus ring, progress bar
  primary-100   #DBEAFE   พื้น badge, แถวที่เลือก
  primary-50    #EFF6FF   พื้น hover ของ sidebar / แถวตาราง

สีพื้นและข้อความ (ขาว-เทา)
  bg            #FFFFFF   พื้นหลังหน้าหลัก
  surface       #F8FAFC   พื้นหลังรอง หัวตาราง
  border        #E2E8F0   เส้นขอบ ตาราง
  text          #0F172A   ข้อความหลัก
  text-muted    #64748B   ข้อความรอง / label

สีสถานะคำขอ (ใช้ให้ตรงกันทั้งระบบ)
  ฉบับร่าง (Draft)            เทา     #64748B
  รอตรวจสอบ (Submit/Review)   เหลือง  #D97706
  อนุมัติ (Approve)           เขียว   #16A34A
  ปฏิเสธ (Reject)             แดง     #DC2626
  จ่ายแล้ว                    น้ำเงิน #1D4ED8

กฎ: สีสถานะต้องมีข้อความกำกับเสมอ ห้ามใช้สีอย่างเดียว

3. เลย์เอาต์ (LAYOUT)
----------------------------------------------------------
โครงหลัก (App Shell)
  - Sidebar ซ้าย กว้าง 240px (ย่อได้เหลือ 72px)
  - Topbar สูง 64px : ชื่อหน้า / ค้นหา / กระดิ่งแจ้งเตือน / ชื่อผู้ใช้ + role
  - พื้นที่เนื้อหา max-width 1280px

ระยะและรูปทรง
  - Grid 12 คอลัมน์ gutter 24px
  - Spacing ฐาน 8px  (8 / 16 / 24 / 32 / 48)
  - Radius: input และปุ่ม 8px, การ์ด 12px
  - เงาการ์ด: 0 1px 2px rgba(15,23,42,.06) เท่านั้น ไม่ใช้เงาหนัก

Responsive
  - 1024px ขึ้นไป : เต็มรูปแบบ
  - 768-1023px    : sidebar ย่อ
  - ต่ำกว่า 768px  : sidebar เป็น drawer, ตารางเลื่อนแนวนอนใน container
                    (ห้ามให้ทั้งหน้าเลื่อนแนวนอน)


----------------------------------------------------------
4. คอมโพเนนต์หลัก (COMPONENTS)
----------------------------------------------------------
ปุ่ม (สูง 40px)
  - Primary   : พื้นน้ำเงินทึบ ตัวอักษรขาว
  - Secondary : ขอบน้ำเงิน พื้นขาว
  - Ghost     : ไม่มีขอบ ใช้กับงานรอง
  - Danger    : แดง ใช้กับ ปฏิเสธ / ลบ

ช่องกรอกข้อมูล (Input) สูง 44px
  - ปกติ  : ขอบ border
  - focus : ขอบ primary-500 + ring 3px
  - error : ขอบแดง + ข้อความอธิบายใต้ช่อง

Status Badge
  - ทรงแคปซูล พื้นสีอ่อน ตัวอักษรสีเข้ม ตามสีสถานะข้อ 1

ตาราง
  - หัวตารางพื้น surface, แถวสูง 52px, hover พื้น primary-50
  - มี pagination, ค้นหา, กรอง
  - ปุ่ม Export Excel มุมขวาบน (เลือกปี / เดือน / รอบการเบิกได้)

Stepper สถานะคำขอ
  - Draft > Submit > Review > Approve / Reject > Email
  - มีปุ่ม "ย้อนกลับทีละขั้น" ตามบทบาทที่มีสิทธิ์

การ์ดสวัสดิการ
  - ชื่อสวัสดิการ / วงเงิน / ใช้ไปแล้ว / คงเหลือ
  - Progress bar และข้อความ "เบิกแล้ว X/30 ครั้ง"

การ์ดผู้อนุมัติ
  - รูป ชื่อ ตำแหน่ง ให้พนักงานเห็นชัดว่าใครเป็นผู้อนุมัติ

t Log Timeline
  - ใคร / ทำอะไร / เมื่อไร / ค่าก่อน-หลังการแก้ไข
  - เห็นได้เฉพาะ Admin, HR, การเงิน (Auditor ดูอย่างเดียว)

Org Tree (โครงสร้างองค์กร)
  - แสดง hierarchy หัวหน้า-ลูกน้อง (1:N)
  - ตัวกรอง แผนก / ตำแหน่ง / ระดับ

Modal / Toast
  - ยืนยันก่อน อนุมัติ / ปฏิเสธ / ย้อนขั้นตอน
  - การปฏิเสธต้องกรอกเหตุผล


----------------------------------------------------------
5. หน้าจอแยกตามบทบาท (เมนู SIDEBAR)
----------------------------------------------------------
พนักงาน
  - Dashboard (วงเงินคงเหลือ)
  - สิทธิ์สวัสดิการของฉัน
  - ยื่นคำขอเบิก
  - ประวัติ / รายการคงค้าง
  - ผู้อนุมัติของฉัน

หัวหน้าแผนก
  - เมนูของพนักงานทั้งหมด
  - เบิกแทนพนักงานในแผนก  
- คำขอรออนุมัติ

HR
  - จัดการข้อมูลพนักงาน (เพิ่ม / แก้ไข / ลาออก)
  - โครงสร้างองค์กร
  - สร้างคำขอสวัสดิการใหม่ (ส่งให้ Admin อนุมัติ)
  - อนุมัติสิทธิ์ / ปรับวงเงิน
  - รายการคงค้าง (สรุปรายวัน / เดือน / ปี)
  - Export Excel

Admin
  - อนุมัติคำขอสร้างสวัสดิการจาก HR
  - ตรวจ Log และความเรียบร้อยของระบบ
  - จัดการสิทธิ์ผู้ใช้

การเงิน
  - รายการรอจ่ายเงิน
  - กำหนดและเลื่อนวันจ่าย
  - Export ตามปี / เดือน / รอบการเบิก
  - ดู Log

หน้า Login
  - การ์ดกลางจอ พื้นหลัง primary-50
  - โลโก้ / อีเมล / รหัสผ่าน / Google reCAPTCHA


----------------------------------------------------------
6. ข้อตกลงร่วมสำหรับทีมออกแบบ
----------------------------------------------------------
 1. ทุกหน้ารายการต้องมี ค้นหา / กรอง / Export / สถานะว่าง (Empty state)
 2. ทุกหน้าต้องมีสถานะ Loading (skeleton) เป้าหมายโหลดภายใน 5 วินาที
 3. ข้อความเป็นภาษาไทยเป็นหลัก ปุ่มใช้คำกริยาสั้น เช่น
    "ส่งคำขอ" "อนุมัติ" "ปฏิเสธ" "ย้อนกลับ"
 4. สิทธิ์ที่ไม่มี ให้ซ่อนเมนู ไม่ใช่แสดงแล้ว disable
